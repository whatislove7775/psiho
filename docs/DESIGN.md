# aprosop — дизайн-система

Анонимная психологическая помощь. Человек приходит в уязвимом состоянии и должен
с первого экрана понять: здесь безопасно, никто не узнает, кто он. Идентичность
пользователя на платформе — это **его аватар** в стиле Memoji, собранный в студии.
Настоящее лицо и имя нигде не появляются.

## Принципы

1. **Аватар — главный герой.** Везде, где в обычном сервисе стояла бы фотография,
   стоит 3D-аватар (сайдбар, карточки диалогов и созвонов, карточки специалистов, звонок).
2. **Тёплое и живое, но спокойное.** Цвета берём из логотипа: градиент
   барвинок → фиалка для главного, искорка, щёки, облачко и сирень — для тем,
   тегов и иллюстраций. Никакого «корпоративного» синего и серых кнопок для
   главного действия. Анимация — только в ответ на действие (hover, открыть,
   подтвердить) и «живой» аватар; уважаем `prefers-reduced-motion`.
3. **Пастельные круги** — быстрые действия (как на референсе); мягкие подложки
   акцентов — темы, теги, обложки, пустые состояния. Семантические цвета
   (успех/ожидание/ошибка) — только для статусов.
4. **Иерархия радиусов:** панель 28 → карточка 22 → контрол 14 → pill 999.
5. **Текст пишется для человека:** простой русский, предложения с заглавной буквы,
   без КАПСА в лейблах, без « · » между словами, без стрелок в тексте кнопок.
   Кнопка говорит, что произойдёт: «Записаться», «Сохранить аватар».
   Ошибка объясняет, что случилось и как исправить. Пустой экран — приглашение к действию.
6. **Качество по умолчанию:** адаптив до 360px, видимый фокус клавиатуры,
   контраст AA, `aria-*` на иконочных кнопках.

## Токены (см. `apps/web/src/styles/tokens.css`)

Тёмная тема по умолчанию, светлая через `[data-theme="light"]`. Нейтрали слегка
подкрашены в индиго, чтобы жить рядом с градиентом логотипа.

### Бренд: градиент логотипа

Плитка логотипа — `#7AA5FF → #3A6DF0 → #6A4FE8` (барвинково-синий → фиалковый).
Это и есть основной акцент сайта (раньше был «корпоративный» синий `#3A6DF0`).

| Токен | Тёмная | Светлая | Роль |
|---|---|---|---|
| `--g-accent` | `linear-gradient(215deg, #7AA5FF, #3A6DF0 46%, #6A4FE8)` | = | большие поверхности: hero, «Ближайший созвон», акцентные карточки (светлый угол справа сверху, белый текст слева — AA) |
| `--g-primary` | `120deg, #4A6DF0 → #525EEC → #6A4FE8` | = | основные кнопки, активные чипы, свои сообщения в чате, выбранный день, прогресс |
| `--g-primary-hover` | чуть светлее | = | hover основных кнопок |
| `--c-primary` | `#525EEC` | `#525EEC` | сплошной средний тон: заливки с белым текстом (5:1), рамки, точки, счётчики |
| `--c-primary-ink` | `#9AA5FF` | `#4652E0` | текст, ссылки и иконки цвета бренда на панелях (AA в обеих темах) |
| `--c-primary-soft` | `rgba(116,128,255,.17)` | `rgba(82,94,236,.11)` | активный пункт меню, мягкая кнопка, бейдж |
| `--c-primary-glow` / `--shadow-primary` | | | цветная тень под основной кнопкой и сценой hero |
| `--focus` | `0 0 0 3px rgba(132,142,255,.6)` | `rgba(82,94,236,.45)` | кольцо фокуса |

Правило: **цвет текста бренда — всегда `--c-primary-ink`**, не `--c-primary`
(у `--c-primary` на тёмной панели контраст всего 3.5:1).

| `--c-raised` / `-2` | `#21212B` / `#2B2B37` | `#F5F5FB` / `#EBEBF5` | элементы внутри карточек, инпуты |
| `--c-text` | `#F4F4F8` | `#0E0E16` | основной текст |
| `--c-muted` | `#9C9CAB` | `#5F5F70` | вторичный |
| `--c-faint` | `#5F5F6E` | `#A3A3B3` | подсказки, disabled |

Семантические цвета не используем как декор.

### Игривые акценты (из логотипа и референса)

Каждый акцент — три токена: `--a-X` (яркая заливка, тёмная иконка сверху),
`--a-X-soft` (подложка: чипы, обложки, пустые состояния), `--a-X-ink`
(читаемый текст/иконка на панели и на своей подложке, AA в обеих темах).

| Акцент | Заливка | Откуда |
|---|---|---|
| `sun` | `#FFDB6E` | искорка логотипа |
| `coral` | `#FF9F85` | щёки, коралловые волосы |
| `cyan` | `#6FD8F2` | облачко «Hello!» |
| `lilac` | `#B9A6FF` | фиалковый край градиента |
| `mint` | `#8FE6C9` | спокойный «дыхательный» |

Где применять: теги тем (`Badge tone="sun|coral|cyan|lilac|mint"`; для темы —
`topicTone(name)` из `lib/topicTone.ts`, одна тема = всегда один цвет), точки в
фильтрах, иконки фактов/шагов, пузыри в углу `Stat`, обложки практик и статей.
Не использовать для статусов (для них — semantic).

Пастели быстрых действий (`QuickAction tone`, иконка `#111`): `peach #FFC2A8`,
`butter #FFE17C`, `lime #D8F28A`, `mint #9FE8D4`, `lilac #C9B9FF`, `sky #A6DCFF`,
`periwinkle #B4C4FF`, `coral #FFAB96`, `cyan #9BE6F6`.

### Живость

- `--g-glow` — 2–3 размытых пятна (барвинок, фиалка, чуть циана) на `body::before`;
  панели остаются непрозрачными, поэтому чтение не страдает.
- `--tex-grain` — «карандашное» зерно: кладётся первым слоем поверх градиента
  (`background: var(--tex-grain), var(--g-accent)`), либо класс `.grain` на любой поверхности.
- Искорка логотипа (4-лучевая звезда `--a-sun`) — только на брендовых сценах (hero, карточка проверки специалистов).
- Микро-взаимодействия: основная кнопка приподнимается с цветным ореолом, пастельные круги
  «подпрыгивают» (`--ease-bounce`), иконки меню чуть поворачиваются. Всё выключается
  при `prefers-reduced-motion`.

## Типографика

Один шрифт — **Onest Variable** (самохостинг, `@fontsource-variable/onest`),
хорошая кириллица. Шкала: 12 / 13 / 15 / 17 / 20 / 24 / 32 / 44 / 60.
Заголовки 600–700, `letter-spacing: -0.02em`. Цифры денег и времени —
`font-variant-numeric: tabular-nums`. Строка текста ≤ 72 символов.

## Раскладка кабинета

```
┌──────────┬──────────────────────────────────┬──────────────┐
│ профиль  │ Заголовок страницы     [действие] │ акцентная    │
│ (аватар) │ подзаголовок                      │ карточка     │
│ ──────── │ ┌──────────────────────────────┐ │ (градиент)   │
│ навигация│ │ контент-карточки               │ │              │
│          │ └──────────────────────────────┘ │              │
│ [CTA]    │                                  │              │
└──────────┴──────────────────────────────────┴──────────────┘
```
Сайдбар 280px — отдельная панель со скруглением 28 и отступом 16 от края.
< 1100px правая колонка уходит под контент; < 760px сайдбар превращается в
нижний таб-бар + верхнюю панель.

## Компоненты (`apps/web/src/ui`)

`Button` (primary / secondary / ghost / danger / white; sizes sm/md/lg; pill),
`Card`, `Panel`, `IconCircle` (пастель + иконка + подпись), `Field`/`Input`/
`Textarea`/`Select`, `Segmented`, `Tabs`, `Badge`, `Stat`, `EmptyState`,
`Modal`, `Toast`, `Spinner`, `Skeleton`, `AvatarThumb` (снимок 3D-аватара).
Иконки — `lucide-react`, 20px, stroke 1.8.

Никаких inline-стилей с хардкод-цветами: только токены (`var(--c-…)`).
Стили — CSS Modules рядом с компонентом.
